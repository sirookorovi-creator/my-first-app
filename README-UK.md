# VOXBRIDGE v0.2 — переклад голосових повідомлень без платного API

**Головне:** на етапі тестування використовуємо **Cloudflare Free**. Платний OpenAI API-ключ більше не потрібний. Моделі працюють безпосередньо через **Cloudflare Workers AI**. Безкоштовна квота — 10 000 neurons на добу. На тарифі Free після вичерпання квоти запити зупиняються, а не оплачуються.

## Що вже зроблено
- Мобільний вебінтерфейс EN/UA з вибором 13 мов спілкування.
- Два приватні посилання (власник і гість), тексти й відповіді, видалення та автоматичне закінчення розмови за 7 днів.
- Обмежений 25 секундами запис голосу, серверна перевірка розміру, згода на зовнішню AI-обробку.
- Голос → текст: `@cf/openai/whisper-large-v3-turbo` у Cloudflare, **не платний OpenAI API**.
- Переклад тексту: `@cf/meta/m2m100-1.2b` у Cloudflare.
- Озвучення перекладу голосом браузера, якщо пристрій підтримує потрібну мову.
- D1 зберігає тексти/переклади до 7 днів; додаток не зберігає аудіофайли.
- Серверні автоматизовані тести з **імітацією** AI, перевірка SQL-міграцій, Wrangler dry-run — через GitHub Actions.

## Статус
**Ще не доведено на реальному сайті:** повноцінна публікація на Cloudflare, справжня робота моделей Workers AI, зокрема WebM/MP4 зі смартфонів, якість різних мовних пар та робота на iPhone Safari/Android Chrome. Тести із заглушками — не підтвердження реального перекладу. Програма **не готова до публічного комерційного запуску**.

## Як запустити сайт без покупки послуг
Покрокова [інструкція українською](DEPLOY-UK.md). База `voxbridge-db` уже створена власником, її ID записаний у `wrangler.jsonc`.

1. Cloudflare: залишити **Workers Free**, платний тариф не вмикати.
2. Створити обмежений Cloudflare API token, дізнатися Account ID.
3. У GitHub зберегти **секрети** `CLOUDFLARE_ACCOUNT_ID` та `CLOUDFLARE_API_TOKEN` (не публікувати).
4. Запустити вручну **Deploy VOXBRIDGE (manual)** у вкладці GitHub Actions.
5. У Cloudflare Worker додати **два різні секрети** `RATE_LIMIT_SALT` (20+ символів) і `LINK_SECRET` (24+ символи). Ніякого `OPENAI_API_KEY` не треба.
6. Протестувати спочатку текстовий переклад, потім голос на реальних телефонах.

### Для розробника локально
```sh
npm install
cp .dev.vars.example .dev.vars
# Вказати два різні довгі секрети, зберігати файл лише локально
npm run db:local
npm run check
npm run dev
```
Локальний AI binding може вимагати входу в Cloudflare, оскільки моделі працюють у хмарі.

## Безпека та обмеження
- Це приватні посилання, а **не** end-to-end шифрування. Будь-хто, кому передали посилання, бачить повідомлення.
- Переклад може помилятися — не використовувати для медичних чи фінансових рішень.
- Для публічного запуску потрібні антибот-захист, приватність/юридичні контакти та перевірка реального навантаження.
- Cloudflare Free обмежує інтенсивність використання. Після вичерпання AI-квоти сервіс може тимчасово перестати перекладати, але не має переходити на платні виклики.
- Репозиторій GitHub зараз публічний. **Ніколи** не розміщувати у ньому токени чи паролі.

Офіційне ціноутворення: https://developers.cloudflare.com/workers-ai/platform/pricing/
