# VOXBRIDGE v0.1 — реальний вебпроєкт для двосторонніх голосових перекладів

**Інструкція без програмування:** [підключення Cloudflare та запуск із GitHub](DEPLOY-UK.md).

**Що працює в коді:** створення розмови, два окремі приватні посилання, запис голосу в браузері, передача аудіо на сервер, розпізнавання мовлення через OpenAI, переклад через OpenAI, спільна історія розмови в D1, голосове відтворення перекладу через синтезатор пристрою, відповіді в обидва боки, ручний текстовий ввід, ліміти використання, автоматичне видалення розмов через 7 днів.

**Що НЕ зроблено/не перевірено:** реальне підключення до OpenAI за платним API-ключем, тест фізичного iPhone/Android, публікація на Cloudflare, платежі, акаунти, push-повідомлення, повноцінна антифрод-система, зовнішні пентести, відновлення/резервні копії. Автоматизовані тести використовують **підставні відповіді AI**, не оплачують і не перевіряють справжній переклад. Озвучення — це стандартний голос браузера, не клон голосу автора.

## Що потрібно

- Mac із Node.js 20+, інтернет
- Безкоштовний акаунт Cloudflare
- **Для справжніх перекладів:** окремий API-ключ OpenAI з доступним балансом; підписка ChatGPT не оплачує API
- Git не обов'язковий

## Запуск локально

```bash
cd voxbridge-mvp
npm install
npx wrangler login
npx wrangler d1 create voxbridge-db
```

Остання команда виведе `database_id` у форматі UUID. Встав його у `wrangler.jsonc` замість `REPLACE_WITH_YOUR_D1_DATABASE_ID`.

Зроби локальний файл `.dev.vars` із шаблону `.dev.vars.example` і заповни три значення:

```
OPENAI_API_KEY=твій_секретний_ключ
RATE_LIMIT_SALT=випадковий_рядок_мінімум_20_символів
LINK_SECRET=інший_випадковий_рядок_мінімум_24_символи
```

Генерація двох секретів на Mac:

```bash
openssl rand -hex 32
openssl rand -hex 32
```

Виконай:

```bash
npm run db:local
npm run dev
```

Відкрий `http://localhost:8787`. Запис аудіо зазвичай доступний на `localhost` або HTTPS; для телефону через звичайний HTTP за IP комп'ютера мікрофон може бути недоступний.

**Важливо:** якщо ключа немає, можна побачити інтерфейс і створити розмову, але справжній переклад не працюватиме. API явно поверне помилку 503 замість вигаданого перекладу.

## Публікація

1. У `wrangler.jsonc` має бути справжній `database_id`.
2. Створи секрети в Cloudflare **окремо**, не у відкритому коді:

```bash
npx wrangler secret put OPENAI_API_KEY
npx wrangler secret put RATE_LIMIT_SALT
npx wrangler secret put LINK_SECRET
```

3. Створи схему віддаленої бази та розгорни застосунок:

```bash
npm run db:remote
npm run deploy
```

4. Wrangler покаже адресу виду `https://voxbridge-mvp.<твій-субдомен>.workers.dev`.
5. Перед поширенням чужим людям перевір політику приватності, обробку персональних даних, ліміти витрат, якість перекладу й умови AI-провайдера.

*Ці інструкції ґрунтуються на Cloudflare Workers Static Assets, D1 migrations і OpenAI Audio API станом на жовтень 2026 року. В середовищі підготовки архіву npm registry недоступний, тому локальне встановлення Wrangler та реальне розгортання не перевірені.*

## Дозвіл на AI-обробку

Перед надсиланням тексту або голосу користувач повинен встановити прапорець згоди. Сервер також перевіряє прапорець. У проєкті є чернетка `/privacy.html`, яку потрібно юридично адаптувати перед публічним запуском.

## Як перевірити, що серверний код живий

```bash
npm run check
```

Тести охоплюють: генерацію токенів, створення розмови, доступ власника/гостя, відновлення запрошення, двосторонні текстові переклади з імітацією AI, надсилання аудіо до імітованого сервісу, ліміти, прострочення й видалення. Тести не перевіряють якість реального аудіо. Окремий браузерний smoke-тест на Chromium з імітованим API: `python tests/browser_smoke.py`. Він перевірив перемикання EN/UA, створення розмови, відповіді, доступ гостя та мобільну ширину. Для нього потрібен Python Playwright.

## Як працює безпека

- 64-символьні токени: посилання автора та співрозмовника різні.
- У БД зберігаються SHA-256 хеші токенів і зашифрована копія токена гостя для відновлення автором.
- Передача аудіо здійснюється OpenAI для транскрибування; аудіофайли на нашому сервері **не зберігаються**.
- Текст оригіналу й переклад зберігаються у Cloudflare D1 до 7 днів, потім видаляються щоденним завданням.
- Одержувач, який має посилання, може переглядати всю розмову та відповідати. Це **capability link**, а не підтверджена особа: не використовуй з медичною, фінансовою або іншою дуже чутливою інформацією.
- За замовчуванням глобальна межа — 25 AI-повідомлень/день, 8 повідомлень/IP/день, 3 нових розмови/IP/день, 20 повідомлень/розмову. Підбираються через `wrangler.jsonc`; ці ліміти не є абсолютною гарантією нульових витрат (є паралельні запити, повторні спроби й тарифи API).
- Не додавати `.dev.vars` у репозиторій, не вставляти секретний ключ у JS браузера.

## Відомі проблеми перед продажем

1. Пряма конкуренція з існуючими перекладачами; механіку самопоширення та готовність платити не доведено.
2. Браузерний синтезатор мовлення інколи не має голосу для мови; на iOS відтворення потребує жесту користувача.
3. Щоб бути справжнім месенджером, знадобляться сповіщення про відповіді, облікові записи, блокування зловживань і узгодження термінів зберігання.
4. Дані перекладу можуть бути неточними; не використовувати як гарантовано точний переклад договорів, ліків, термінових інструкцій тощо.
5. За відсутності окремого API-балансу справжні транскрипція та переклад не працюватимуть.

## Файли

- `public/index.html` — англомовний адаптивний інтерфейс
- `public/styles.css` — дизайн без сторонніх runtime-бібліотек
- `public/app.js` — поведінка, мікрофон, програвач, посилання
- `src/index.js` — Cloudflare Worker з API
- `migrations/0001_init.sql` — D1 схема
- `tests/worker.test.js` — тести із заглушками AI та бази
- `wrangler.jsonc` — конфігурація

## Критерій реального MVP

Дві різні людини на двох смартфонах можуть пройти шлях: створити кімнату → записати → відкрити посилання → прослухати переклад → записати відповідь → прослухати її переклад. Поки це не перевірено на реальній інфраструктурі та справжніх пристроях, проєкт слід називати **перевіреним у модульних тестах кодом MVP**, а не запущеним продуктом.
